# Sharpshooter

This is a game written in ActionScript 3, using the Starling engine for GPU acceleration.

Once the code is compiled, levels, graphics, animations, interactions, hitboxes, everything is configurable through external files located in the src/assets folder. See existing files for reference.

I know ActionScript is a dead language, but it bears a strong resemblance to modern TypeScript. The principles are timeless. The language is irrelevant. The principles of Object Oriented Programming are something that's not taught enough. Web development training is still built on a system that was engineered around document presentation, not full featured applications. OOP is key to creating applications that scale, are easily maintained, avoid repetitious code, and don't collapse under their own weight of spaghetti code.

Sprite sheets are made with [TexturePacker](https://www.codeandweb.com/texturepacker).

Article regarding this codebase and lessons to be learned from it has been submitted to HackerNoon. I will update this README with a link once the article is published.
